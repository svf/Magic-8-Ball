# Magic-8-Ball
A Chicken Scheme Implimentation of the Magic 8 Ball

## Intepreted (quickest for testing):

```bash
csi -script magic-8-ball.scm "Will it rain tomorrow?"

## Compiled (if you want a standalone binary):

```bash
csc magic-8-ball.scm -o magic-8-ball
./magic-8-ball "Shoule I take the job?"
